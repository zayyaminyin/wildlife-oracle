# Wildlife Oracle

A cinematic mobile-first PWA for National Park lovers. Wildlife Oracle forecasts likely wildlife encounters by park, season, habitat, and time of day using curated mock data and an immersive editorial interface.

## Run Locally

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173`.

## Features

- Explore parks through a full-bleed visual feed
- Forecast species sighting odds with season, time, and habitat controls
- Inspect park habitats, safety notes, and wildlife watch windows
- Save parks and species to a local watchlist
- Installable PWA shell with local generated assets
